    Tiempos

    Iconos de herramientas

    Si apagas una, esa herramienta muestra solo la cara. El interruptor de Iconos de herramientas de arriba las apaga todas.

    Leyendo la pantalla

    • Franja inferior: activity heartbeat. One column per 5 seconds, a spark for each tool call, so you can see a busy or stalled session from across the room.
    • Puntos arriba a la izquierda: running sub-agents.
    • Cuadrado arriba a la derecha: the build after a push. Amber blinking is running, green passed, red failed.
    • Gotas de sudor: the task has been running a long time.
    • Saltando y saludando, con destellos amarillos: Claude is waiting on you. It breaks through a clock or timer for a few seconds, then goes back.
    • Confeti: salio un push o se ejecutaron tests. Un numero grande sobre una barra: resultados de tests. Glitch: a tool failed.
    • Tablero: each small face has a coloured stripe on top that matches the colour in the session list above.

    Que puede hacer Claude

    Estas reglas se aplican a las herramientas de Claude y a los hooks automaticos de estado. Tus clics en este panel nunca se limitan. Una peticion bloqueada aparece en Actividad, y Claude recibe el motivo.

    Control de ClaudeInterruptor general. Apagado significa que Claude y los hooks no pueden tocar la pantalla para nada.
    Caras automaticas de estadoCaras que siguen lo que hace Claude Code (pensando, trabajando, hecho, te necesita). Sin llamar a ninguna herramienta.
    Claude puede ignorar una pantalla fijadaNormalmente fijar bloquea a Claude por completo.

    00:00

    La pantalla muestra minutos sobre segundos y una barra de progreso. Al terminar, la cara te saluda.

    Medidor del sistema

    Dos barras en pantalla: CPU arriba, memoria abajo. Verde, ambar, rojo.

    Rotacion

    Pasa solo por caras, mensajes y el medidor del sistema.

    Latencia de red

    Un grafico de cuanto tarda una conexion a 1.1.1.1, lo mas reciente a la derecha. Verde es rapido, rojo lento; un punto rojo abajo significa que la sonda fallo.

    Bateria y disco

    Dos barras: bateria arriba (se omite en un PC de sobremesa) y llenado del disco del sistema abajo. Cuanto mas lleno, mas rojo.

    Vigilancia y tiempo

    Sitios

    Un sitio cuenta como caido tras dos fallos seguidos. Entonces la pantalla parpadea con su nombre, y vuelve a verde cuando se recupera.

    En el altavoz: un cuadrado por sitio, hasta 16. Verde: arriba; ambar: lento; rojo: caido; gris: esperando la primera comprobacion.
